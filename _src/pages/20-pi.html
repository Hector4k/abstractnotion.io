Project Intelligence
The problem

Every After Effects project is a black box to everyone but its author.

A finished project can hold hundreds of comps and thousands of layers. The knowledge of how it is wired — which comp renders, which pre-comp drives the logo, which font the client approved — lives in one artist's head.

When that artist moves on, the next person spends days reverse-engineering the file. Project Intelligence turns every project into a record you can hand off, revisit, or archive with confidence.

Features

What it captures.

Comments, promoted

Notes that survive the project

After Effects lets you comment on any layer or item, but nothing ever surfaces those comments. Project Intelligence lists every comment in the project in one place — inside After Effects or out — and lets you organize and tag them, so you can leave a crumb trail for your future self or the next artist.

Handoff & archive

Diagnose in minutes, not days

Mark which comps are the render comps and which ones matter, and write notes about how the project is wired and how the compositions relate. Whoever opens it next gets a map of the build before opening a single comp.

Visual record

A flipbook of every project

Project Intelligence captures thumbnails, not just metadata — for every composition, or every asset, your choice. Each one gets a short sequence of frames rather than a single still, so you can recognize a comp at a glance without rendering anything.

Offline library

Answers without chasing the artist

Every project is indexed into a library the whole team can search offline. Artists, leads, and producers can look up which fonts, colors, logo version, and file paths a past project used — without launching After Effects.

How it works

Three parts, one record.

  1. Panel inside After EffectsA panel reads the open project — comps, layers, comments, footage, fonts, and colors — and captures thumbnail frames.
  2. Desktop libraryA standalone macOS and Windows app keeps each capture as a searchable, offline record, readable without opening After Effects.
  3. Notes & handoffTag comments, flag render comps, and write the map of the build, then hand the record to the next artist or archive it with the project.

Where are my project records kept?

Project Intelligence is local-first: records live in a library on your own machine, searchable offline. Shared options for teams — local-network and cloud sync — are on the roadmap and will always be opt-in.
