What it captures

One record that outlives the project file.

Structure

How it's wired

Every composition, how they nest and relate, and which ones are the render comps that matter — a map of the build you can read before, or instead of, opening a single comp.

The artist's context

Notes that travel with the project

Look & type

Technical detail

Real data

Read from the project, not guessed.

Everything in a Project Intelligence record is read directly from the After Effects project or written by the artist who built it. No AI summarizes or interprets your work, so the record says exactly what the project contained — nothing invented, nothing paraphrased.

How it works

Capture, annotate, archive.

  1. CaptureA panel inside After Effects reads the open project — comps, layers, comments, media, fonts, colors, effects — and captures thumbnail frames.
  2. AnnotateThe artist flags the render comps and adds notes on how the project is wired, while that knowledge is still fresh.
  3. Archive & searchThe record goes into an offline library on macOS or Windows that anyone on the team can search without launching After Effects.

Questions

Frequently asked.

Does Project Intelligence use AI?

No. Everything in a record comes straight from the After Effects project or from notes a person wrote. The name is about the knowledge it keeps, not artificial intelligence.

Does it copy my media files?

It records every media item the project used — name, format, and original path — along with thumbnails, so you know what the project needs even when the media is gone. Keep using After Effects' Collect Files to archive the media itself.

Can I read a record without After Effects?

Yes. The library is a standalone macOS and Windows app, so producers and anyone else can search records without an After Effects license.

When will it be available?

It is in private testing with working artists now. Email us with the subject "Project Intelligence" to join the early-access list.
